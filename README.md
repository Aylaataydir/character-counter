

# Frontend Mentor - Character counter

A real-time character, word, and sentence counter with letter density analysis.


## Features

- **Real-time counting**: Characters, words, and sentences
- **Character limit**: Set a custom character limit (optional)
- **Space exclusion**: Count characters with or without spaces
- **Letter density analysis**: Visual breakdown of letter frequency with percentage bars
- **Theme toggle**: Switch between dark and light modes
- **Responsive design**: Works seamlessly on all devices


## Built With

- HTML5
- CSS3
- Flexbox/Grid for layout
- Vanilla JavaScript


## What I Learned

- Cleaning and parsing text with regex patterns
- Building progress bars and calculating percentages
- Creating a light/dark theme toggle system
- Manipulating data with array methods (sort, filter, map)
- Making progress bars scale dynamically
